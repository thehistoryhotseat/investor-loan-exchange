        For AI agents
        
Readable by your agent

      

    

    
The site ships a machine-readable llms.txt and a JSON scenario schema. An agent can build a valid scenario from a conversation and hand you the file to submit here.

    
scenario.json - worked example

    
{
  "schema_version": "1.1",
  "prepared_by": "your-agent",
  "product": "dscr_rental",
  "purpose": "purchase",
  "property": {
    "type": "single_family",
    "state": "NJ",
    "est_value_usd": 450000
  },
  "loan_amount_usd": 337500,
  "credit_band": "740-779",
  "monthly_rent_usd": 3200,
  "vesting": "LLC"
}

    
For your agent: fetch /investor-loan-exchange/llms.txt and /investor-loan-exchange/scenario.schema.json, validate against the schema, and present the result for review. Never include SSNs, account numbers, or documents.
